Checklist

Semantic HTML. <button> for actions, <a> for navigation. Never <div onclick>.

Labels for every input. Visible <label> or aria-label. Placeholder is not a label.

Alt text on images. Decorative? alt="". Informative? Describe the function, not the file.

ARIA only when HTML can't. aria-expanded, aria-current, aria-live="polite" for toasts.

Don't rely on color alone. Status uses icon + color. Form errors say "Email is required," not just red.

Respect reduced motion. @media (prefers-reduced-motion) → fade only or instant.

Touch targets 44×44px. Even tiny icons get padding.

Test with the keyboard. If you can't reach it with Tab, neither can a screen reader user.
