# WeaveCode Web — UI Kit

A hi-fi recreation of the WeaveCode marketing surface. Built from the brand kit (logos, color/type PDFs, grafismos). No production codebase was provided, so component shapes are inferred from the brand DNA.

## Files

- `index.html` — full marketing page wired together
- `Header.jsx` — top nav with logo + nav + CTA
- `Hero.jsx` — dot-grid + glow + Georgia accent headline
- `Services.jsx` — three-up service cards
- `Verticals.jsx` — Beauty / Health / Business product strip
- `CaseStudy.jsx` — case-study showcase block
- `CTASection.jsx` — purple full-bleed CTA with curly-brace flourish
- `Footer.jsx` — minimal footer with links + reproduction of vertical lockup

## How to use

Open `index.html` in the browser. Components are loaded as separate Babel scripts from this folder.

## Caveats

- This is a recreation; without a real production site we used standard product-studio patterns (hero / services / case study / CTA / footer).
- All copy is bilingual-friendly but currently in English; mirror PT-BR voice rules from `../../README.md` when localising.
